BanglaThon হলো বাংলা ও Banglish—উভয় মাধ্যমে লেখা সম্পূর্ণ মৌলিক ও স্বতন্ত্র একটি প্রোগ্রামিং ল্যাঙ্গুয়েজ। ব্রাউজারে সরাসরি লিখে প্র্যাকটিস করুন এবং নিজস্ব কম্পিউটারে মাত্র ১ কমান্ডে ইনস্টল করুন।

১-কমান্ড ইনস্টলেশন

টার্মিনালে কপি করে পেস্ট করুন — সাথে সাথেই প্রস্তুত!

আপনার অপারেটিং সিস্টেম বেছে নিন, কমান্ডটি কপি করে Terminal বা PowerShell-এ রান করুন।

Windows PowerShell খুলুন এবং নিচের কমান্ডটি পেস্ট করে Enter চাপুন (স্বয়ংক্রিয়ভাবে নেটিভ বাইনারি ও পাথ কনফিগার হবে):

irm https://raw.githubusercontent.com/tasfiqueofficial/BanglaThon/main/install.ps1 | iex
১

অটোমেটিক ইঞ্জিন ও Exe

নিজে থেকেই ~১০ MB পোর্টেবল ইঞ্জিন ও নেটিভ bangla.exe সেটআপ হয়ে যাবে—কোনো স্ক্রিপ্ট ব্লক এরর নেই।

২

VS Code এক্সটেনশন অটো-সেটআপ

পিসিতে VS Code থাকলে রঙিন Syntax Highlighting ও ▶ Run বাটন অটোমেটিক যুক্ত হয়ে যাবে।

৩

কোড রান করুন

যেকোনো ফোল্ডারে tas.bl লিখে চালান: bangla run tas.bl অথবা bangla লিখে লাইভ কনসোল খুলুন।

Terminal (macOS Apple Silicon/Intel বা Linux) খুলুন এবং নিচের কমান্ডটি পেস্ট করে Enter চাপুন:

curl -fsSL https://raw.githubusercontent.com/tasfiqueofficial/BanglaThon/main/install.sh | sh
১

জিরো-ঝামেলা সেটআপ

স্বয়ংক্রিয়ভাবে নেটিভ ইঞ্জিন ও কমান্ডলাইন পাথ সিস্টেমে যুক্ত হয়ে যাবে।

২

গ্লোবাল CLI ও VS Code

যেকোনো ডিরেক্টরিতে bangla কমান্ড কাজ করবে এবং VS Code এক্সটেনশন অটো-ইনস্টল হয়ে যাবে।

৩

রান করুন

প্রোগ্রাম চালাতে লিখুন: bangla run tas.bl (টার্মিনাল না পেলে একবার source ~/.zshrc দিন)।

ডেভেলপার এবং অবদানকারীদের জন্য সরাসরি GitHub থেকে সোর্স কোড ক্লোন করে বিল্ড করার সহজ নিয়ম:

git clone https://github.com/tasfiqueofficial/BanglaThon.git && cd BanglaThon

GitHub main ব্রাঞ্চ থেকে সম্পূর্ণ ওপেন-সোর্স কোডবেস ডাউনলোড হবে।

২

লোকাল বিল্ড ও লিংক

লোকাল সোর্স ফোল্ডারে প্রবেশ করে সরাসরি নেটিভ সিএলআই এক্সিকিউট করুন।

৩

টেস্ট ও রান

কমান্ডলাইন থেকে সহজে যাচাই করুন: bangla --version অথবা bangla run tas.bl

অভ্র থেকে বাংলাথন — ভাষার মুক্তি
“ফ্রি। ভাষার জন্য টাকা নেবো কেন?”
— মেহদী হাসান খান
অভ্র কিবোর্ডের জনক (২০০৩) • মূলমন্ত্র: “ভাষা হোক উন্মুক্ত”

অভ্র কিবোর্ডের উত্থান থেকেই আমাদের এই যাত্রার জন্ম

২০০৩ সালে মেহদী হাসান খান যখন অভ্র কিবোর্ড সবার জন্য উন্মুক্ত করে দিয়েছিলেন, তখন তিনি শুধু একটি সফটওয়্যার বানাননি—তিনি বাঙালিকে নিজের ভাষায় কম্পিউটারে লেখার স্বাধীনতা দিয়েছিলেন। কেউ অভ্রর দাম জানতে চাইলে তিনি বলেছিলেন: “ফ্রি। ভাষার জন্য টাকা নেবো কেন?”

BanglaThon সেই একই উত্তরাধিকার বহন করে। অভ্র আমাদের দিয়েছে মাতৃভাষায় লেখার স্বাধীনতা, আর BanglaThon এনে দিচ্ছে মাতৃভাষায় কোড লেখা ও প্রোগ্রামিং করার স্বাধীনতা।

২০০৩ • অভ্র কিবোর্ড (Avro) ভাষা হলো লেখা-উন্মুক্ত ফোনেটিক ও ইউনিকোডে বাংলা লেখা সবার হাতের মুঠোয় আসে।
২০২৬ • বাংলাথন (BanglaThon) ভাষা হলো কোড-উন্মুক্ত Banglish ও বাংলা—দুই মাধ্যমেই শিক্ষার্থীরা নিজের ভাষায় প্রোগ্রামিং শিখবে।
আমাদের অঙ্গীকার: ভাষার জন্য কখনোই কোনো টাকা নেওয়া হবে না। BanglaThon প্রতিটি শিক্ষার্থী, শিক্ষক ও প্রতিষ্ঠানের জন্য আজীবন ১০০% ফ্রি এবং ওপেন-সোর্স থাকবে।
সহজ ও শক্তিশালী

কেন BanglaThon দিয়ে প্রোগ্রামিং শুরু করবেন?

নিজস্ব Lexer, Recursive-Descent Parser ও Tree-Walking Interpreter দিয়ে শূন্য থেকে নির্মিত।

বাংলা + Banglish সিনট্যাক্স

শুরুতে অভ্যস্ত হতে dekhao বা সরাসরি বাংলায় দেখাও, ধরি, যদি ও বাংলা সংখ্যা ০-৯—দুটোই একসাথে ব্যবহার করা যায়।

স্বতন্ত্র নেটিভ রানটাইম

সম্পূর্ণ মৌলিক ও স্বয়ংসম্পূর্ণ এক্সিকিউশন ইঞ্জিন—কোনো বাহ্যিক জটিল ডিপেন্ডেন্সি ছাড়াই এক কমান্ডেই যে কোনো সিস্টেমে প্রস্তুত হয়ে যায়।

VS Code অটো-ইকোসিস্টেম

অফিশিয়াল VS Code Extension-এ রয়েছে বাংলা কীওয়ার্ড Syntax Highlighting, অটো-স্নিপেট এবং ১-ক্লিক ▶ Run বাটন।

কাজ বাংলা সিনট্যাক্স Banglish সিনট্যাক্স উদাহরণ
প্রিন্ট করা (Output) দেখাও dekhao দেখাও "তুমি কেমন আছো"
ভ্যারিয়েবল ঘোষণা ধরি / ধরো dhori ধরি বয়স = ২০
ইনপুট নেওয়া নাও(...) nao(...) ধরি নাম = নাও("নাম: ")
শর্ত (If / Else) যদি / নাহলে jodi / nahole যদি (ক > ৫) { ... } নাহলে { ... }
লুপ (Loops) জন্য / যতক্ষণ jonno / jotokkhon জন্য (ধরি ক = ১; ক <= ৫; ক += ১) { ... }
ফাংশন ও রিটার্ন কাজ / ফেরত kaj / ferot কাজ যোগ(ক, খ) { ফেরত ক + খ }
তালিকা (Array) তালিকা(...) বা [...] talika(...) যুক্তকরো, সাজাও, যোগ_করো, সর্বোচ্চ
গণিত ও রূপান্তর বর্গমূল, ঘাত, পূর্ণ borgomul, ghat, purno ২ ** ৩, পূর্ণ("৪২")
মৌলিকত্ব ও কোডিং মানদণ্ড

বাংলাথন অফিশিয়াল স্টাইল গাইড ও কোডিং স্ট্যান্ডার্ড

একটি স্বয়ংসম্পূর্ণ প্রথম-শ্রেণীর ভাষার মতো বাংলাথনের রয়েছে নিজস্ব কোডিং কনভেনশন, নান্দনিক সিনট্যাক্স নীতি ও মৌলিক স্থাপত্য রীতি।

০১

অর্থপূর্ণ নামকরণ রীতি (Naming Conventions)

ভ্যারিয়েবল ও ফাংশনের নাম সবসময় অর্থপূর্ণ বাংলা শব্দ বা snake_case ব্যবহার করে লিখুন। একক বর্ণ বা অস্পষ্ট নাম পরিহার করুন। ধ্রুবক (Constants)-এর জন্য বড় হাতের বা স্পষ্ট নাম দিন।

✓ আদর্শ পদ্ধতি ধরি মোট_টাকা = ৫০০
কাজ গড়_নির্ণয়(ক, খ) { ... }
✗ অনুৎসাহিত ধরি x = ৫০০ # অস্পষ্ট
কাজ f(a, b) { ... }
০২

কোড বিন্যাস ও ৪-স্পেস ইনডেন্টেশন (Formatting)

প্রতিটি শর্ত (যদি / jodi), চক্র (যতক্ষণ / jotokhon) ও ফাংশন ব্লকে ৪-স্পেস সমমানের পরিষ্কার ইনডেন্টেশন বজায় রাখুন। অপারেটরের দুই পাশে স্পেস দিন।

✓ আদর্শ পদ্ধতি যদি (বয়স >= ১৮) {
    দেখাও "যোগ্য ভোটার"
}
✗ অনুৎসাহিত যদি(বয়স>=১৮){দেখাও"যোগ্য ভোটার"}
০৩

ডুয়েল-ডায়লেক্ট ভারসাম্য (.bl বনাম .bng)

বাংলা স্ক্রিপ্টের জন্য .bl ও রোমানাইজড বাংলিশ স্ক্রিপ্টের জন্য .bng ফাইল এক্সটেনশন ব্যবহার করুন। একই ফাইলে বাংলা ও বাংলিশ কীওয়ার্ডের খিচুড়ি মিশ্রণ এড়িয়ে ধারাবাহিকতা বজায় রাখুন।

✓ আদর্শ পদ্ধতি ধরি ফলাফল = ৮০
যদি (ফলাফল >= ৮০) { দেখাও "A+" }
✗ অনুৎসাহিত dhori ফলাফল = ৮০
jodi (ফলাফল >= ৮০) { দেখাও "A+" }
০৪

মানবিক মন্তব্য ও স্পষ্ট এরর সচেতনতা

কোডের যুক্তি ও উদ্দেশ্য স্পষ্ট করতে # দিয়ে সহজ মাতৃভাষায় মন্তব্য (Comments) লিখুন। কোনো এরর ঘটলে বাংলাথন ডায়াগনস্টিক বার্তা ও লাইন নম্বর দেখে ত্রুটি সংশোধন করুন।

✓ আদর্শ পদ্ধতি # শিক্ষার্থী পাস করেছে কিনা যাচাই
যদি (নম্বর >= ৩৩) { দেখাও "পাস" }
✗ অনুৎসাহিত # কোড শুরু
