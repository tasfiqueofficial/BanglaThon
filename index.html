১-কমান্ড ইনস্টলেশন

টার্মিনালে কপি করে পেস্ট করুন — সাথে সাথেই প্রস্তুত!

আপনার অপারেটিং সিস্টেম বেছে নিন, কমান্ডটি কপি করে Terminal বা PowerShell-এ রান করুন।

Windows PowerShell খুলুন এবং নিচের কমান্ডটি পেস্ট করে Enter চাপুন (আলাদা কোনো Python ইনস্টল থাকা লাগবে না!):

irm https://raw.githubusercontent.com/tasfiqueofficial/BanglaThon/main/install.ps1 | iex
১

অটোমেটিক ইঞ্জিন ও Exe

নিজে থেকেই ~১০ MB পোর্টেবল ইঞ্জিন ও নেটিভ bangla.exe সেটআপ হয়ে যাবে—কোনো স্ক্রিপ্ট ব্লক এরর নেই।

২

VS Code এক্সটেনশন অটো-সেটআপ

পিসিতে VS Code থাকলে রঙিন Syntax Highlighting ও ▶ Run বাটন অটোমেটিক যুক্ত হয়ে যাবে।

৩

কোড রান করুন

যেকোনো ফোল্ডারে tas.bl লিখে চালান: bangla run tas.bl অথবা bangla লিখে লাইভ কনসোল খুলুন।

Terminal (macOS Apple Silicon/Intel বা Linux) খুলুন এবং নিচের কমান্ডটি পেস্ট করে Enter চাপুন:

curl -fsSL https://raw.githubusercontent.com/tasfiqueofficial/BanglaThon/main/install.sh | sh
১

জিরো-ঝামেলা সেটআপ

পিসিতে Python না থাকলে কোনো Xcode পপআপ ছাড়াই পোর্টেবল ইঞ্জিন নিজেই ডাউনলোড করে নেবে।

২

গ্লোবাল CLI ও VS Code

যেকোনো ডিরেক্টরিতে bangla কমান্ড কাজ করবে এবং VS Code এক্সটেনশন অটো-ইনস্টল হয়ে যাবে।

৩

রান করুন

প্রোগ্রাম চালাতে লিখুন: bangla run tas.bl (টার্মিনাল না পেলে একবার source ~/.zshrc দিন)।

যাদের পিসিতে আগে থেকেই Python ও pip আছে, তারা সরাসরি GitHub থেকে ইনস্টল বা আপডেট করতে পারেন:

pip install --upgrade git+https://github.com/tasfiqueofficial/BanglaThon.git

অভ্র কিবোর্ডের জনক (২০০৩) • মূলমন্ত্র: “ভাষা হোক উন্মুক্ত”

অভ্র কিবোর্ডের উত্থান থেকেই আমাদের এই যাত্রার জন্ম

২০০৩ সালে মেহদী হাসান খান যখন অভ্র কিবোর্ড সবার জন্য উন্মুক্ত করে দিয়েছিলেন, তখন তিনি শুধু একটি সফটওয়্যার বানাননি—তিনি বাঙালিকে নিজের ভাষায় কম্পিউটারে লেখার স্বাধীনতা দিয়েছিলেন। কেউ অভ্রর দাম জানতে চাইলে তিনি বলেছিলেন: “ফ্রি। ভাষার জন্য টাকা নেবো কেন?”

BanglaThon সেই একই উত্তরাধিকার বহন করে। অভ্র আমাদের দিয়েছে মাতৃভাষায় লেখার স্বাধীনতা, আর BanglaThon এনে দিচ্ছে মাতৃভাষায় কোড লেখা ও প্রোগ্রামিং করার স্বাধীনতা।

২০০৩ • অভ্র কিবোর্ড (Avro) ভাষা হলো লেখা-উন্মুক্ত ফোনেটিক ও ইউনিকোডে বাংলা লেখা সবার হাতের মুঠোয় আসে।
২০২৬ • বাংলাথন (BanglaThon) ভাষা হলো কোড-উন্মুক্ত Banglish ও বাংলা—দুই মাধ্যমেই শিক্ষার্থীরা নিজের ভাষায় প্রোগ্রামিং শিখবে।
আমাদের অঙ্গীকার: ভাষার জন্য কখনোই কোনো টাকা নেওয়া হবে না। BanglaThon প্রতিটি শিক্ষার্থী, শিক্ষক ও প্রতিষ্ঠানের জন্য আজীবন ১০০% ফ্রি এবং ওপেন-সোর্স থাকবে।
সহজ ও শক্তিশালী

কেন BanglaThon দিয়ে প্রোগ্রামিং শুরু করবেন?

নিজস্ব Lexer, Recursive-Descent Parser ও Tree-Walking Interpreter দিয়ে শূন্য থেকে নির্মিত।
