১. ভূমিকা, দর্শন ও জাতীয় প্রয়োজনীয়তা

১.১ পটভূমি ও ভাষাগত দেয়াল (The Linguistic Barrier)

বাংলাদেশে প্রাথমিক, মাধ্যমিক ও উচ্চ-মাধ্যমিক স্তরের ৮৫% এরও বেশি শিক্ষার্থী বাংলা মাধ্যমে পড়াশোনা করে। কিন্তু যখনই তারা কম্পিউটার সায়েন্স, আইসিটি বা প্রোগ্রামিংয়ের জগতে প্রবেশ করে, তাদের সামনে এক বিশাল ভাষাগত প্রাচীর দাঁড়িয়ে যায়। পৃথিবীর প্রায় সব মূলধারার প্রোগ্রামিং ল্যাঙ্গুয়েজ (C++, Java, Python) ইংরেজি কি-ওয়ার্ডের ওপর নির্ভরশীল।

শিক্ষাতাত্ত্বিক গবেষণায় প্রমাণিত হয়েছে যে, একজন নতুন শিক্ষার্থীকে একই সাথে অ্যালগরিদমিক লজিক এবং বিদেশি ইংরেজি শব্দ বুঝতে বাধ্য করলে তার মস্তিষ্কে ৬০% অতিরিক্ত মানসিক চাপ (Cognitive Overhead) তৈরি হয়। ফলে কোটি কোটি মেধাবী শিক্ষার্থী শুরুতেই হতাশ হয়ে প্রোগ্রামিং শেখা ছেড়ে দেয়।

১.২ ড. মেহেদী হাসান খান ও অভ্র কি-বোর্ডের অনুপ্রেরণা

❝ ভাষার জন্য টাকা নেবো কেন? ❞
— ড. মেহেদী হাসান খান (স্বপ্নদ্রষ্টা: অভ্র কি-বোর্ড, একুশে পদকপ্রাপ্ত ২০২৫/২০২৬)

২০০৩ সালে তরুণ মেডিকেল শিক্ষার্থী ডা. মেহেদী হাসান খান যখন বাংলা লেখার যুগান্তকারী সফটওয়্যার 'অভ্র' তৈরি করেন, তখন বড় ভাইদের বাণিজ্যিক অফার প্রত্যাখ্যান করে তিনি বলেছিলেন—"ভাষার জন্য টাকা নেবো কেন?" এবং তাঁর স্লোগান ছিল—"ভাষা হোক উন্মুক্ত"।

১.৩ অবাণিজ্যিক অঙ্গীকার (Our Non-Commercial Ethos)

আমরা বিশ্বাস করি, যে ভাষার তরে ১৯৫২ সালে আমাদের পূর্বপুরুষেরা রক্ত দিয়ে রাজপথ রঞ্জিত করেছিলেন, সে ভাষার শিক্ষামূলক প্রযুক্তিকে আমাদের টিম কখনো কোনো বাণিজ্যিক পণ্য বা পেইড সার্ভিসে রূপান্তর করবে না। অভ্র যেমন কোটি বাঙালির জন্য বাংলা লেখাকে উন্মুক্ত করেছিল, বাংলথন (BanglaThon) তেমনি কোটি শিক্ষার্থীর জন্য কোডিং ও অ্যালগরিদম শেখাকে আজীবন সম্পূর্ণ উন্মুক্ত ও ফ্রি (FOSS) রাখবে।

১.৪ মূল লক্ষ্য ও উদ্দেশ্যসমূহ

  • তৃণমূল ডিজিটাল রূপান্তর: গ্রাম ও চরাঞ্চলের প্রতিটি স্কুলের শিক্ষার্থীদের কাছে প্রোগ্রামিং সহজবোধ্য করা।
  • স্বাধীন ইন্টারপ্রেটার আর্কিটেকচার: কোনো ব্রাউজার নির্ভরতা বা পাইথন টেক্সট-র‍্যাপার নয়; সম্পূর্ণ নিজস্ব লেক্সার ও পার্সার দিয়ে গঠিত পূর্ণাঙ্গ সিস্টেম।
  • সিপি (Competitive Programming) ফোকাসড: ইন-বিল্ট সর্টিং, সর্বোচ্চ-সর্বনিম্ন মান নির্ণয় ও ফাস্ট আই/ও মেকানিজম।

২. ডাউনলোড ও ইনস্টলেশন নির্দেশিকা

বাংলথন অত্যন্ত হালকা ও আধুনিক। এর সবচেয়ে বড় সুবিধা হলো শূন্য ডিপেন্ডেন্সি (Zero External Dependencies)—বাড়তি কোনো লাইব্রেরি ছাড়াই যেকোনো পিসিতে এটি সরাসরি চলবে।

২.১ পদ্ধতি ১: উইন্ডোজ PowerShell ১-লাইন ইনস্টলার (স্বয়ংক্রিয়)

উইন্ডোজ ১০ ও ১১ ব্যবহারকারীরা কোনো ফাইল ডাউনলোড না করেই সরাসরি PowerShell ওপেন করে নিচের ১টি লাইন পেস্ট করে এন্টার দিলেই পুরো সেটআপ স্বয়ংক্রিয়ভাবে সম্পন্ন হবে:

irm https://raw.githubusercontent.com/tasfiqueofficial/BanglaThon/main/install.ps1 | iex
ইনস্টল শেষে ফাইল রান করবেন যেভাবে:
নতুন যেকোনো CMD বা PowerShell উইন্ডো খুলে সরাসরি লিখুন:
• ফাইল রান করতে: bangla run apnar_file.bl
• লাইভ কোড লিখতে: bangla

২.২ পদ্ধতি ২: পাইথন pip ১-লাইন ইনস্টলার (উইন্ডোজ, ম্যাক ও লিনাক্স)

যেকোনো কম্পিউটারের টার্মিনাল বা CMD থেকে সরাসরি গিটহাব প্যাকেজ ইনস্টল করতে:

pip install git+https://github.com/tasfiqueofficial/BanglaThon.git

২.৩ পদ্ধতি ৩: গিট ক্লোন ও সোর্স থেকে ইনস্টলেশন

সম্পূর্ণ সোর্সকোড ও টেস্টসহ নিজের পিসিতে নামিয়ে ইনস্টল করতে:

git clone https://github.com/tasfiqueofficial/BanglaThon.git cd BanglaThon pip install .

২.৪ পদ্ধতি ৪: সাধারণ জিপ (ZIP) ও অফলাইন পেনড্রাইভ মোড

যাদের কম্পিউটারে Git নেই তারা github.com/tasfiqueofficial/BanglaThon থেকে Download ZIP দিয়ে আনজিপ করে ভেতর থেকে pip install . দিতে পারবেন। ইন্টারনেটরহিত প্রান্তিক স্কুলের ল্যাবে পেনড্রাইভে ফোল্ডারটি নিয়ে সরাসরি python main.py <file.bl> দিয়েও চলবে।

৩. কোড লেখার নিয়ম ও এক্সিকিউশন মোড

৩.১ প্রথম প্রোগ্রাম রচনা (hello.bl)

আপনার কম্পিউটারের যেকোনো টেক্সট এডিটর (যেমন: Notepad, VS Code) দিয়ে একটি নতুন ফাইল তৈরি করুন এবং সেভ করুন hello.bl নামে:

# এটি আমার প্রথম বাংলাথন প্রোগ্রাম dekhao "আসসালামু আলাইকুম বাংলাদেশ!" dekhao "বাংলা ভাষায় কোডিং এখন বাস্তব।" dhori shongkha_a = 25 dhori shongkha_b = 15 dekhao "যোগফল: " + (shongkha_a + shongkha_b)

৩.২ টার্মিনাল থেকে ফাইল এক্সিকিউট করা

টার্মিনাল বা সিএমডি ওপেন করে ফাইলটি রান করার কমান্ড:

# স্ট্যান্ডার্ড রান কমান্ড: bangla run hello.bl # সরাসরি ফাইল পাথ দিয়েও চলবে: bangla hello.bl

৩.৩ লাইভ ইন্টারেক্টিভ মোড (Interactive REPL Mode)

Python-এর মতো বাংলাথনেও রয়েছে একটি উচ্চক্ষমতাসম্পন্ন ইন্টারেক্টিভ কনসোল (REPL)। টার্মিনালে কোনো আর্গুমেন্ট ছাড়া শুধু bangla লিখলেই লাইভ মোড চালু হয়:

$ bangla Bangla Programming Language v0.1.0 — Interactive Mode Exit korte 'exit' likhun >> dhori x = 100 >> dhori y = 50 >> dekhao x - y 50 >> jodi (x > y) { dekhao "x boro!" } x boro! >> exit Bidai!

৩.৪ ফাইল এক্সটেনশন নীতি

বাংলাথন সোর্স কোড মূলত দুটি এক্সটেনশন সমর্থন করে:

  • .bl (Bangla Language) — স্ট্যান্ডার্ড এক্সটেনশন।
  • .bng (Bangla Script) — এক্সটেন্ডেড স্ক্রিপ্ট সমর্থন।

৩.৫ মন্তব্য ও ডকুমেন্টেশন (Comments)

কোডের মাঝে মন্তব্য লিখতে হ্যাশ (#) চিহ্ন ব্যবহার করা হয়। ইন্টারপ্রেটার এটি এড়িয়ে যায়:

# এটি একটি সিঙ্গেল-লাইন কমেন্ট dhori roll = 101 # রোল নম্বর সেট করা হলো

৪. ভেরিয়েবল, ডেটা টাইপ ও অপারেটরস

৪.১ ভেরিয়েবল ঘোষণা ও অ্যাসাইনমেন্ট

বাংলাথনে যেকোনো ভেরিয়েবল তৈরি করতে dhori কি-ওয়ার্ড ব্যবহার করা হয়:

dhori boyosh = 21 # নতুন ভেরিয়েবল তৈরি dhori naam = "Tasfique" # স্ট্রিং ভেরিয়েবল boyosh = 22 # বিদ্যমান ভেরিয়েবলের মান পরিবর্তন

৪.২ সমর্থিত ডেটা টাইপসমূহ (Data Types)

ডেটা টাইপ বাংলাথনে উদাহরণ ইংরেজি সমতুল্য বিবরণ
Number dhori x = 42, 3.14 int / float পূর্ণসংখ্যা ও দশমিক সংখ্যা
String "সোনার বাংলা" str ইউনিকোড ও ল্যাটিন টেক্সট
Boolean shotti / mittha bool (True/False) লজিক্যাল সত্য বা মিথ্যা
List/Array talika(1, 2, 3) list / array ডাইনামিক অ্যারে মেমোরি
Null khali None / null শূন্য বা অনির্ধারিত মান

৪.৩ গাণিতিক অপারেটরস (Arithmetic Operators)

dekhao 10 + 5 # যোগ (১৫) dekhao 10 - 5 # বিয়োগ (৫) dekhao 10 * 5 # গুণ (৫০) dekhao 10 / 4 # ভাগ (২.৫) dekhao 10 % 3 # মডুলাস বা ভাগশেষ (১)

৪.৪ তুলনামূলক অপারেটরস (Comparison Operators)

তুলনার ফলাফল হিসেবে সর্বদা shotti অথবা mittha রিটার্ন করে:

dekhao 5 > 3 # shotti (বৃহত্তর) dekhao 5 < 3 # mittha (ক্ষুদ্রতর) dekhao 5 == 5 # shotti (সমান) dekhao 5 != 3 # shotti (অসমান)

৪.৫ লজিক্যাল অপারেটরস (Logical Operators)

বাংলাথনে ইংরেজি and, or, not-এর বদলে সরাসরি বাংলা শব্দ ব্যবহৃত হয়:

dekhao shotti ebong shotti # shotti (Logical AND) dekhao shotti ba mittha # shotti (Logical OR) dekhao noy shotti # mittha (Logical NOT)

৫. কন্ট্রোল ফ্লো (Control Flow)

৫.১ শর্তযুক্ত শাখা (jodi / nahole)

শর্ত সাপেক্ষে কোড চালানোর জন্য jodi এবং বিকল্পের জন্য nahole ব্যবহৃত হয়:

dhori marks = 75 jodi (marks >= 80) { dekhao "গ্রেড: A+" } nahole jodi (marks >= 70) { dekhao "গ্রেড: A" } nahole { dekhao "আরও ভালো করতে হবে!" }

৫.২ হোয়াইল লুপ (jotokkhon)

যতক্ষণ একটি শর্ত সত্য থাকে, ততক্ষণ ব্লকটি পুনরাবৃত্তি করতে jotokkhon ব্যবহৃত হয়:

dhori shongkha = 1 jotokkhon (shongkha <= 5) { dekhao "গণনা: " + shongkha shongkha = shongkha + 1 }

৫.৩ ফর লুপ (jonno)

সি-স্টাইল ক্লাসিক্যাল ৩-অংশের ফর লুপ চালানোর সিনট্যাক্স:

jonno (dhori i = 0; i < 5; i = i + 1) { dekhao "ধাপ নম্বর: " + i }

৫.৪ লুপ নিয়ন্ত্রণ (thamo ও cholo)

লুপ তাৎক্ষণিকভাবে থামাতে thamo (break) এবং পরবর্তী পুনরাবৃত্তিতে চলে যেতে cholo (continue) ব্যবহৃত হয়:

jonno (dhori i = 1; i <= 10; i = i + 1) { jodi (i == 3) { cholo # ৩ স্কিপ করবে } jodi (i == 7) { thamo # ৭-এ পৌঁছে লুপ বন্ধ হয়ে যাবে } dekhao i }

৬. ফাংশন ও স্কোপ আর্কিটেকচার

৬.১ ফাংশন ডিক্লারেশন (kaj ও ferot)

বাংলাথনে যেকোনো সাবরুটিন বা ফাংশন তৈরি করতে kaj কি-ওয়ার্ড ব্যবহৃত হয়। ফলাফল রিটার্ন করতে ferot ব্যবহৃত হয়:

kaj jogfol(a, b) { ferot a + b } dhori ans = jogfol(12, 18) dekhao "যোগফল হলো: " + ans # আউটপুট: ৩০

৬.২ রিটার্ন ছাড়া ফাংশন (Procedure)

kaj shagotom(user) { dekhao "স্বাগতম, " + user + "!" } shagotom("তাসফিক")

৬.৩ স্কোপিং নিয়ম (Lexical Scoping)

ফাংশনের ভেতর তৈরি ভেরিয়েবল বাইরে অ্যাক্সেসযোগ্য নয় (Local Scope):

dhori global_x = 100 kaj test_scope() { dhori local_y = 50 dekhao global_x # ১০০ প্রিন্ট হবে (গ্লোবাল অ্যাক্সেসযোগ্য) dekhao local_y # ৫০ প্রিন্ট হবে } test_scope() # dekhao local_y # এটি চালালে এরর আসবে: variable পাওয়া যায়নি

৬.৪ রিকার্সিভ ফাংশন (Recursion in BanglaThon)

ফ্যাক্টরিয়াল নির্ণয়ে রিকার্শন কলিংয়ের নিখুঁত রূপায়ন:

kaj factorial(n) { jodi (n <= 1) { ferot 1 } ferot n * factorial(n - 1) } dekhao "৫ এর ফ্যাক্টরিয়াল: " + factorial(5) # ১২০

৭.১ সিপি ও অ্যারে বিল্ট-ইন ফাংশন তালিকা

dhoirgo(x) dhoirgo(arr) বা dhoirgo("বাংলা") তালিকা বা স্ট্রিংয়ের মোট উপাদান সংখ্যা (Length)

jog_koro(L) jog_koro(my_list) তালিকার সকল সংখ্যার সমষ্টি নির্ণয় (Sum)
shorbo_boro(L) shorbo_boro(my_list) তালিকার সর্বোচ্চ মান শনাক্তকরণ (Max Element)
shorbo_choto(L) shorbo_choto(my_list) তালিকার সর্বনিম্ন মান শনাক্তকরণ (Min Element)
