# BanglaThon VS Code Extension

Official VS Code language support for **BanglaThon** (`.bl`, `.bng`).

## Features

- **Dual Syntax Highlighting:** Color-coded keywords, strings, numbers (`0-9` & `০-৯`), built-ins, operators, and comments for both **Banglish** (`dhori`, `jodi`, `dekhao`) and **Native Bangla** (`ধরি`, `যদি`, `দেখাও`).
- **1-Click Run Button (`▶`):** Click the Play button in the top-right editor bar (or press `Cmd+Alt+R` / `Ctrl+Alt+R`) to run `.bl` and `.bng` programs cleanly with full UTF-8 Bangla output.
- **Smart Interactive Terminal Mode:** Automatically runs in an integrated terminal when your program uses `nao()` / `নাও()` input.
- **Bangla & Banglish Code Snippets:** Type `dekhao`/`দেখাও`, `dhori`/`ধরি`, `jodi`/`যদি`, `jonno`/`জন্য`, `kaj`/`কাজ` + Tab.
