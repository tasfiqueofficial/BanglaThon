THE NEED & PHILOSOPHY প্রয়োজনীয়তা ও দার্শনিক ভিত্তি

In Bangladesh and West Bengal, over 300 million people think, conceptualize, and solve problems in Bengali. Yet, programming education has remained gated behind foreign English syntax and opaque compiler diagnostics.

The Avro Keyboard Parallel: Two decades ago, Dr. Mehdi Hasan Khan transformed desktop computing with Avro Keyboard under the historic creed: "ভাষা হোক উন্মুক্ত" (Language should be free). BanglaThon carries that exact torch into the 21st century software domain: মাতৃভাষায় কোডিং হোক উন্মুক্ত!

Under Bangladesh's National Curriculum, ICT is mandatory for millions of secondary and college students. However, over 70% struggle with rote memorization of foreign symbols (#include <stdio.h>, printf, scanf) before grasping algorithmic thinking.

Figure 1. Overcoming the triple cognitive barrier. BanglaThon isolates computational thinking from foreign language anxiety, establishing pure algorithmic intuition.
CORE USE CASES & DIALECTS বাস্তব ব্যবহার ও ডুয়েল ডায়লেক্ট

BanglaThon is engineered with 100% Dual-Dialect Parity. Students can write programs in rich Unicode Bengali or phonetic Banglish, catering to any keyboard setup:

Pure Bengali (.bl) ইউনিকোড
কাজ ফিবোনাচ্চি(পদ) {
  যদি (পদ <= ১) {
    ফেরত পদ
  }
  ফেরত ফিবোনাচ্চি(পদ - ১) +
        ফিবোনাচ্চি(পদ - ২)
}
ধরি উত্তর = ফিবোনাচ্চি(৭)
দেখাও "উত্তর: " + উত্তর
Phonetic Banglish (.bng) বাংলিশ
kaj fibonacci(pod) {
  jodi (pod <= 1) {
    ferot pod
  }
  ferot fibonacci(pod - 1) +
        fibonacci(pod - 2)
}
dhori uttor = fibonacci(7)
dekhao "Result: " + uttor
Figure 2. Full dual-dialect syntax parity. Both scripts compile into identical Abstract Syntax Trees (AST) and run on the same deterministic engine.
SYSTEMS ENGINEERING ARCHITECTURE ইঞ্জিনিয়ারিং আর্কিটেকচার ও কম্পাইলার ডিজাইন

Building a programming language for a complex Brahmic script like Bengali presents distinct systems challenges that standard ASCII lexers fail to handle:

  • Zero-Python Dependency Runtime: Most educational tools fail in rural school labs because students cannot install Python, pip, or configure environment PATHs. BanglaThon bundles an isolated, standalone CPython embedded engine with zero external dependencies.
  • Unicode NFC Normalization Engine: Bengali script uses combining vowel marks (কার), virama (হসন্ত), and rephs. Decomposed Unicode points break identifier matching. Our lexer enforces NFC composition (Unicode TR15) before tokenization, preventing token fragmentation.
  • Pratt Precedence AST Synthesizer: Operator precedence climbing ensures arithmetic (+, -, *, /, %) and boolean logic (এবং, বা, নয়) resolve with absolute mathematical precision.

USER POINT OF VIEW & DX ইউজার পয়েন্ট অব ভিউ ও ডেভেলপার এক্সপেরিয়েন্স

A language is only as powerful as its developer tools. For BanglaThon, we prioritized seamless Developer Experience (DX) for both novice 8th graders and competitive programmers:

  • VS Code Extension (TasfiqueOfficial.banglathon-vscode): Verified and published on the official Microsoft VS Code Marketplace, supporting syntax highlighting, error diagnostics, and custom file tree icons.
  • The Font Shaping Breakthrough (বাংলাথন কনসোল): Standard command terminals (VS Code xterm.js, Windows cmd) break Bengali vowel marks into disconnected fragments (আ◌পন◌ার ন◌াম). We engineered a dedicated Chromium DOM-rendered Webview console that renders complex Brahmic ligatures with 100% typographic fidelity!
  • Contextual Bengali Error Engine: Instead of terrifying error codes (SIGSEGV or IndexOutOfBounds), BanglaThon pinpoints exact line numbers with gentle, actionable Bengali suggestions.
  • 1-Line Universal Installer: Single copy-paste terminal script (install.ps1 for Windows, install.sh for Mac/Linux) configures engine and editor in < 30 seconds.
Figure 4. Terminal Indic shaping innovation. Bypassing xterm.js character-cell grids with a real-time DOM streaming panel guarantees flawless Bengali typographic rendering.
ROADMAP & FUTURE VISION ভবিষ্যৎ রূপরেখা ও জাতীয় লক্ষ্য

  • Bengali Scientific Computing: Built-in math & matrix libraries (গণিত, ম্যাট্রিক্স, গ্রাফ) for high school and university lab simulations.
