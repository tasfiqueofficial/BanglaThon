THE PROBLEM
Every mainstream language uses English keywords. Bengali-medium beginners must decipher an alien vocabulary while simultaneously learning logic—imposing a 60% cognitive overhead that drives capable students away from computer science.

KEY ARCHITECTURAL FEATURES
🔤 Banglish Syntax
dhori, jodi, nahole, jonno, dekhao. Bangla phonetics in Latin letters—works seamlessly on any standard keyboard with zero IME requirements.
🏛️ Independent Grammar
Own recursive-descent parser and Abstract Syntax Tree (AST). It does not borrow another language's runtime or rely on browser engines.
⚡ Built for CP (Competitive Prog.)
Built-in array ops, 2D matrices, recursion, shajao() (sort), shorbo_boro() (max), gcd, prime checking, and fast I/O.
🛡️ Bangla Error Messages
Errors are pinpointed in clear Bengali with exact line & column tracking, plus intelligent "Did you mean...?" suggestions for typo resolution.
💻 Standalone Offline Tool
Runs 100% offline from terminal CLI or REPL. Install once with pip and use the bangla command globally from any directory.
🚀 Optimized Dispatch Engine
A precomputed AST dispatch table replaces dynamic reflection lookups, slashing average runtime by ~31.5%.
