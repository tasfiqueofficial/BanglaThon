🔍 ১. সমস্যা ও পটভূমি (Problem Statement) MOTIVATION

বাংলাদেশে স্কুল ও কলেজ পর্যায়ে কম্পিউটার বিজ্ঞানে শিক্ষার্থীদের প্রধান প্রতিবন্ধকতা ইংরেজি সিনট্যাক্স। লজিক ও অ্যালগরিদম শেখার চেয়ে ইংরেজি কি-ওয়ার্ড মনে রাখা শিক্ষার্থীদের জন্য ৬০% বেশি মানসিক চাপ (Cognitive Load) তৈরি করে।

  • ▸ ভাষাগত দেয়াল: তৃণমূল পর্যায়ে বিপুল প্রতিভাবান শিক্ষার্থী ইংরেজি সিনট্যাক্সের ভীতিতে প্রোগ্রামিং থেকে মুখ ফিরিয়ে নেয়।
  • ▸ ধারণাগত জটিলতা: মাতৃভাষায় লজিক শেখা ও অ্যালগরিদমিক চিন্তা গঠন যেকোনো বিদেশি ভাষার চেয়ে দ্বিগুণেরও বেশি কার্যকর।

🎯 ২. উদ্ভাবনী সমাধান (Core Objectives) INNOVATION

  • ✓ মৌলিক ইন্টারপ্রেটার: কোনো ট্রান্সপাইলার বা পাইথন র‍্যাপার নয়; সম্পূর্ণ নিজস্ব লেক্সার, পার্সার এবং এবস্ট্রাক্ট সিনট্যাক্স ট্রি (AST)।
  • ✓ দ্বৈত সিনট্যাক্স সাপোর্ট: রোমানাইজড বাংলা (যেমন- dhori, jodi, dekhao) ও বাংলা ইউনিকোড উভয় সমর্থন।
  • ✓ সিপি-কেন্দ্রিক (CP-Focused): প্রতিযোগিতামূলক প্রোগ্রামিংয়ের জন্য অত্যন্ত হালকা, দ্রুত ও মেমোরি-সাশ্রয়ী।
  • ✓ বাংলা এরর মেসেজ: কোডে ভুল হলে স্পষ্ট বাংলা ভাষায় লাইভ ডিবাগিং সহায়তা।

📖 ৩. সিনট্যাক্স ও কি-ওয়ার্ড ম্যাপিং GRAMMAR

BanglaThon C++ / Python কাজ ও তাৎপর্য
dhori let / int / var ভেরিয়েবল ঘোষণা
jodi / nahole if / else শর্তযুক্ত শাখা (Conditional)
jotokkhon while হোয়াইল লুপ
jonno for (init; cond; step) ফর লুপ এক্সিকিউশন
kaj ... ferot function ... return ফাংশন সংজ্ঞা ও মান ফেরত
dekhao / nao print() / input() আউটপুট প্রদর্শন ও ইনপুট গ্রহণ
talika(...) list / array ডাইনামিক অ্যারে মেমোরি
shotti / mittha true / false বুলিয়ান মান যাচাই

💻 ৫. লাইভ কোড ডেমোস্ট্রেশন (Live Code) SAMPLE SCRIPT

# ফিবোনাচ্চি সিরিজ ও শর্তযুক্ত অ্যালগরিদম kaj fibonacci(n) { jodi (n <= 1) { ferot n } ferot fibonacci(n - 1) + fibonacci(n - 2) } dhori shongkha = 7 dekhao "৭ম ফিবোনাচ্চি সংখ্যা: " + fibonacci(shongkha) # বিল্ট-ইন ফাংশন ও অ্যারে সর্টিং dhori marks = talika(85, 42, 96, 77, 63) dekhao "সর্বোচ্চ নম্বর: " + shorbo_boro(marks) dekhao "সাজানো তালিকা: " + shajao(marks)

🛡️ ৬. বাংলায় ইন্টেলিজেন্ট এরর রিপোর্টার DIAGNOSTICS

শিক্ষার্থীদের ভীতি দূর করতে BanglaThon লাইন ও কলাম ট্র্যাক করে সুনির্দিষ্ট বাংলা ডায়াগনস্টিক বার্তা দেয়:

ত্রুটি: 'undefined_var' নামে কোনো variable পাওয়া যায়নি (Line 3, Col 12)
ত্রুটি: শূন্য দিয়ে ভাগ করা সম্ভব নয় (Division by zero)
ত্রুটি: অ্যারে ইনডেক্স সীমার বাইরে (Index out of range)

⚡ ৭. সিপি বিল্ট-ইন ফাংশন লাইব্রেরি CP BUILT-INS

dhoirgo(x) অ্যারে বা স্ট্রিংয়ের দৈর্ঘ্য নির্ণয়
juktokoro(L, val) তালিকায় নতুন উপাদান পুশ/যোগ করা
shajao(L) অ্যালগরিদমিক সর্টিং (Ascending Sort)
ulto(x) অ্যারে/স্ট্রিং বিপরীতকরণ (Reverse)
jog_koro(L) তালিকার উপাদানের সমষ্টি (Summation)
shorbo_boro(L) সর্বোচ্চ মান দ্রুত শনাক্তকরণ (Max)
shorbo_choto(L) সর্বনিম্ন মান শনাক্তকরণ (Min)

🧪 ৮. পরীক্ষণ ও কর্মক্ষমতা (Validation) EMPIRICAL PROOF

  • ✓ ৩০/৩০ ইউনিট টেস্ট পাস (১০০% সাফল্য): রিকার্শন, অ্যারে মিউটেশন, স্কোপ বাউন্ডিং, গাণিতিক প্রিসিডেন্স এবং এরর ট্র্যাকিং সম্পূর্ণ ত্রুটিমুক্ত।
  • ✓ CLI ও REPL সাপোর্ট: সরাসরি গ্লোবাল bangla কমান্ড দিয়ে যেকোনো .bl ফাইল চালানো ও লাইভ ইন্টারেক্টিভ কনসোল।
  • ✓ দ্রুত কার্যক্ষমতা: মেমোরি কনজাম্পশন মাত্র < ১৫ MB, যা সাধারণ যেকোনো স্কুল কম্পিউটারে সাবলীল চলে।
